# Pokemon Battle Simulator

## Description

Pokemon Battle Simulator is a turn-based battle game written in Python for my Programming Languages final project.

The player chooses one Pokémon while the computer randomly selects another Pokémon. Both trainers battle until one Pokémon faints.

## Features

- 9 playable Pokémon
- Turn-based combat
- Type effectiveness (Fire, Water, Grass)
- Critical hits
- Move accuracy
- Healing potions
- Random computer opponent
- Object-Oriented Programming design

## Programming Concepts

This project demonstrates:

- Classes and Objects
- Encapsulation
- Inheritance
- Composition
- Modular Programming

## Project Files

- `main.py` – Starts the game
- `battle.py` – Battle mechanics
- `pokemon.py` – Pokémon classes
- `player.py` – Player class
- `move.py` – Move class
- `pokemon_data.py` – Pokémon and move data
- `type_chart.py` – Type effectiveness

## How to Run

```bash
python main.py
```
